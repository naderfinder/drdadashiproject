# DrDadashi Task Manager

وب‌اپ ساده مدیریت کارها بر اساس سند نیازمندی فاز ۱.

## اجرا

این نسخه یک وب‌اپ استاتیک است و برای MVP به Backend یا Database خارجی نیاز ندارد. فایل `index.html` را با یک وب‌سرور استاتیک اجرا کنید؛ برای مثال GitHub Pages یا هر static hosting.

## امکانات MVP

- ایجاد، ویرایش و حذف Task
- تغییر وضعیت
- تعیین اولویت و سررسید
- جست‌وجو و فیلتر
- مرتب‌سازی
- داشبورد آماری
- ذخیره پایدار در `localStorage`
- رابط Responsive

## وضعیت فازها

- فاز ۱: تحلیل نیازمندی‌ها — انجام شد
- فاز ۲: معماری — انجام شد
- فاز ۳: هسته مدیریت کارها — انجام شد
- فاز ۴: رابط کاربری — انجام شد
- فاز ۵: Authentication — برای نسخه بعدی طراحی شده و عمداً خارج از MVP نگه داشته شده
- فاز ۶: تست و استقرار — مستندات و چک‌لیست آماده شده؛ استقرار نهایی نیازمند انتخاب سرویس میزبانی است
