# فازهای ۳ و ۴ — پیاده‌سازی هسته و رابط کاربری

## فاز ۳

هسته MVP در `app.js` پیاده‌سازی شده است:

- Create Task
- Read/List Task
- Update Task
- Delete Task با تأیید کاربر
- تغییر وضعیت
- اولویت
- تاریخ سررسید
- جست‌وجو
- فیلتر وضعیت و اولویت
- مرتب‌سازی
- نگهداری `created_at` و `updated_at`
- persistence در `localStorage`

اعتبارسنجی اولیه عنوان در Client انجام می‌شود و داده‌های نمایشی با HTML escaping رندر می‌شوند.

## فاز ۴

رابط کاربری در `index.html` و `styles.css` پیاده‌سازی شده است:

- Dashboard آماری
- فرم ایجاد/ویرایش مشترک
- فهرست کارت‌محور Taskها
- badge برای وضعیت و اولویت
- طراحی Responsive برای دسکتاپ و موبایل
- حالت خالی برای فهرست بدون نتیجه
- پیام خطای فرم
- دسترسی پایه با `aria-label` و `aria-live`

## محدودیت فعلی

این نسخه هنوز Authentication، Backend و Database سمت سرور ندارد. بنابراین Taskها به همان مرورگری که در آن ایجاد شده‌اند وابسته‌اند. این محدودیت عمدی و مطابق MVP فاز ۱ است.
