# فاز ۶ — تست و کنترل کیفیت

## چک‌لیست دستی MVP

### Task CRUD
- [ ] ایجاد Task با عنوان معتبر
- [ ] جلوگیری از ایجاد Task بدون عنوان
- [ ] ویرایش عنوان، توضیحات، وضعیت، اولویت و سررسید
- [ ] حذف با تأیید
- [ ] تغییر وضعیت به انجام‌شده و بازگشت به انجام‌نشده

### Search / Filter / Sort
- [ ] جست‌وجوی عنوان
- [ ] جست‌وجوی توضیحات
- [ ] فیلتر وضعیت
- [ ] فیلتر اولویت
- [ ] مرتب‌سازی جدیدترین/قدیمی‌ترین
- [ ] مرتب‌سازی سررسید و اولویت

### Persistence
- [ ] ایجاد چند Task
- [ ] Refresh صفحه
- [ ] اطمینان از باقی‌ماندن Taskها
- [ ] بررسی رفتار فهرست خالی

### Responsive
- [ ] دسکتاپ
- [ ] تبلت
- [ ] موبایل
- [ ] باز و بسته‌شدن فرم

## تست‌های امنیتی پایه

- [ ] ورودی عنوان/توضیحات شامل HTML به‌صورت متن نمایش داده شود.
- [ ] داده حساس در localStorage ذخیره نشود.
- [ ] در نسخه Backend، authorization برای هر Task در سرور کنترل شود.

## تست‌های اتوماتیک پیشنهادی برای فاز Backend

- unit tests برای validation و business rules
- integration tests برای CRUD API
- authentication/authorization tests
- E2E برای جریان ایجاد تا حذف Task

> در این MVP چون منطق به DOM و Web Storage وابسته است، تست‌های Browser/E2E برای پوشش واقعی مناسب‌تر از یک test runner سمت Node هستند. قبل از Production باید این چک‌لیست اجرا و نتیجه ثبت شود.
